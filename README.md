# 8-BIT TITLE SCREENS · CHP

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **THIS ONE TIME AT BAND CAMP**.

8-BIT TITLE SCREENS (CHP) — the recognizable melodies that actually ring a bell, rendered as NES 2A03 chiptune: two pulse squares (12.5/25/50% duty, built from the pulse Fourier series), a triangle bass, and noise drums. EIGHT public-domain classics — Ode to Joy (Beethoven), Für Elise (Beethoven), Eine kleine Nachtmusik (Mozart), In the Hall of the Mountain King (Grieg), Canon in D (Pachelbel), Greensleeves (trad.), William Tell gallop (Rossini), Habanera/Carmen (Bizet) — each looping like a title screen and downloadable as a ~12s .wav (rendered live via OfflineAudioContext, no server). ⚑ IP-clean by design: the famous game tunes (Mario/Zelda/Mega Man) are COPYRIGHTED and deliberately absent; only PUBLIC-DOMAIN compositions are used (composers dead 150+ years → compositions PD worldwide), and the chiptune arrangement + synthesis are original, generated in-browser — no sampled or copyrighted recording/arrangement touched. Pairs with [[the-sapphic-melody]]'s NES corner. David Lee Wise / Bridge-Burners LLC.
